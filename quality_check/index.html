📐 ISO 19157:2013 — Data Quality Reference

Each quality category is classified according to ISO 19157:2013. The classification uses the standard's 5 main quality elements:

Thematic Accuracy

• Non-quantitative Attribute Accuracy • Classification Correctness • Quantitative Attribute Accuracy

Logical Consistency

• Topological Consistency • Conceptual Consistency • Format Consistency • Domain Consistency

Temporal Accuracy

• Temporal Validity • Temporal Consistency • Accuracy of a Time Measurement

Positional Accuracy

• Absolute or External Accuracy • Relative or Internal Accuracy • Gridded Data Position Accuracy

Completeness

• Commission (excess data) • Omission (missing data)
Note: Completeness is evaluated in a zonal-based fashion in the OSWM Completeness Map.

Bold sub-elements are currently used in the per-feature quality checks.

Explaining Each category:

improper_keys : Keys that (almost certainly) shouldn't be used at that feature type — ISO 19157: Thematic Accuracy → Non-quantitative Attribute Accuracy
uncanny_keys : Keys that may be OK in some specific situations, but may be a mistake — ISO 19157: Thematic Accuracy → Non-quantitative Attribute Accuracy
keys_without_wiki : Keys that may be wrong, because there's no wiki article for it — ISO 19157: Thematic Accuracy → Non-quantitative Attribute Accuracy
replaceable_values : values that are not wrong, but there's a better option that is in the commentary — ISO 19157: Thematic Accuracy → Non-quantitative Attribute Accuracy
wrong_mispelled_or_unlisted_values : Values that are probably wrong, but they may be mispelled or just unlisted — ISO 19157: Thematic Accuracy → Non-quantitative Attribute Accuracy
invalid_characters : characters that should not be in the value or in the key — ISO 19157: Logical Consistency → Format Consistency
older_than_five_years : Features that haven't been updated in over five years, potentially outdated. — ISO 19157: Temporal Accuracy → Temporal Validity
missing_tags : Features that are missing important tags — ISO 19157: Completeness → Omission (missing data)
disjointed_geometries : Features with geometries that are not connected to others, i.e. disjointed. This is generally a special matter of concern for crossings, kerbs and sidewalks — ISO 19157: Logical Consistency → Topological Consistency
improper_geometries : Features with geometries (more specifically geometry types) that are incompatible with the main tags — ISO 19157: Logical Consistency → Conceptual Consistency
crossings_lacking_kerbs : Crossings that intersect fewer than 2 kerbs. — ISO 19157: Logical Consistency → Topological Consistency
kerb_on_top_of_non_crossing : Kerbs that do not intersect any crossing geometry. — ISO 19157: Logical Consistency → Topological Consistency
