Read this map as a screening tool

Hazards are inferred from available OSM attributes and a global terrain model. A feature with no detected hazard is not certified safe.

  • Missing tactile, surface or kerb data remains unknown; it is never treated as "no".
  • Longitudinal terrain slope is contextual and directional. Cross slope is used only when incline:across=* is explicitly mapped.
  • Surface-material rules are provisional proxies. Critical means either an apparent barrier or an extreme contextual safety risk—the popup states which.
